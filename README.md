# Speech To Text

> A [Claude Code](https://code.claude.com/docs/en/skills) skill.

Transcribe audio to text using ElevenLabs Scribe v2. Use when converting audio/video to text, generating subtitles, transcribing meetings, or processing spoken content.

## Install

Via [skills.sh](https://skills.sh):

```bash
npx skills add marks97/speech-to-text
```

Or manually — copy the `speech-to-text/` folder into your `.claude/skills/` directory.

## Usage

Once installed, Claude invokes this skill automatically when your request matches
what it does (see the triggers in [`speech-to-text/SKILL.md`](speech-to-text/SKILL.md)). You can
also ask for it by name.

See [`speech-to-text/SKILL.md`](speech-to-text/SKILL.md) for the full workflow, scripts, and options.
